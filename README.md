## 🚀 Tecnologias

- Java 17
- JavaFX
- Maven
- JDBC
- MySQL
- Scene Builder

---

## ✨ Funcionalidades

- ✅ Cadastro de vendedores
- ✅ Atualização de dados
- ✅ Exclusão de registros
- ✅ Consulta de vendedores
- ✅ Associação com departamentos
- ✅ Interface gráfica em JavaFX

## ⚙️ Como executar

```bash
git clone https://github.com/Raphael-Java/javafx-desktop.git
```

Configure o banco MySQL no arquivo:

```
db.properties
```

Depois execute:

```
Main.java
```
